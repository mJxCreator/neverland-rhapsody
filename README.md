# Neverland Rhapsody

> A Rust-based Voxel Sandbox Engine

用 Rust 从零实现的 Minecraft 风格体素沙盒引擎，当前处于可交互 Demo 阶段。

**自研引擎核心逻辑，不自研 GPU 驱动与图形 API** —— 底层通过 `wgpu` 调用 GPU，把精力集中在引擎本身的架构与算法上。

## 当前状态

`v0.10` 已可运行：`cargo run` 打开窗口，玩家以独立实体存在于动态区块世界中，拥有 0.6×1.8 的 AABB 碰撞体、重力、跳跃与地面/空中移动。物理以固定 60 Hz 步长推进，单帧最多补算 5 步，摄像机用插值系数平滑跟随；WASD 移动、空格跳跃，可在任意区块边界连续行走，撞墙、撞天花板与落地均由碰撞检测决定。玩家脚下的方块被破坏后会自然下落；未加载区块被视为实体屏障，阻止玩家进入尚未生成的地形；右键放置方块时不能放进玩家自身碰撞体内。世界仍只保留玩家周围 7×7×2 的区块，并在卸载时保护玩家所在区块及一圈邻居；准星选中、破坏/放置与按区块存档沿用 v0.9 行为。

## 第一版目标

一个可运行、可交互的体素沙盒 Demo：

- 第一人称自由移动的 3D 世界
- Minecraft 风格的方块地形
- 挖掘与放置方块
- 区块加载与基础地形生成
- 基础方块材质与光照
- 世界保存与读取

### 自研模块

| 模块 | 职责 |
| --- | --- |
| World | 世界管理系统 |
| Block | 方块数据系统 |
| Chunk | 区块管理系统 |
| ChunkManager | 动态区块加载、卸载与网格重建调度 |

| Physics | 固定步长重力、跳跃、地面/空中移动与 AABB 碰撞 |
| Raycast | 方块射线检测 |
| Terrain | 程序化地形生成 |

## 快速开始

前置要求：Rust stable 工具链（`cargo`、`rustc`）。

```bash
git clone <repo-url>
cd neverland-rhapsody
cargo run
```

> `cargo run` 会打开一个 1280×720 的窗口。WASD 前后左右移动，空格跳跃；左键点击窗口捕获鼠标以转动视角，捕获后左键破坏选中方块、右键在命中面外侧放置方块，按 Esc 释放，再次按 Esc 退出。
> Windows + MinGW 环境若为 mcfgthread 变体，链接参数已在 `.cargo/config.toml` 中补全。

构建与质量检查：

```bash
cargo build
cargo test
cargo clippy --all-targets -- -D warnings
cargo fmt --check
```

## 开发约定

- **模块化优先**：即使只是 Demo，也不把逻辑塞进 `main.rs`。
- **自研边界**：GPU 驱动与图形 API 不自研；引擎核心逻辑不调用现成游戏引擎。
- **定位与进度分离**：`codemap.md` 记录“代码在哪”，`progress.md` 记录“做到哪、下一步做什么”，两者不混写。
- **完成定义**：构建通过、静态检查无警告、测试通过、codemap 与 progress 同步，才算一项任务完成。
- **变更历史交给 Git**：文档中不保留“已废弃”“旧路径”类历史条目。
